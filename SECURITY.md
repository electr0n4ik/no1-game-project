# Политика безопасности

## Поддерживаемые версии

| Версия | Поддержка |
|--------|-----------|
| 0.1.x  | ✅        |

## Как сообщить об уязвимости

**Не создавайте публичный Issue для уязвимостей.**

1. Откройте приватное уведомление:
   **Security → Advisories → Report a vulnerability** в этом репозитории, либо
2. напишите владельцу через GitHub (`@electr0n4ik`) с меткой `security`.

Ожидаемый срок ответа: **72 часа**. После подтверждения уязвимость
исправляется в приоритетном порядке; кредит исследователя — по желанию.

## Область внимания

- Рекламные SDK (Yandex Mobile Ads, VK Ad Network): утечки идентификаторов,
  обход согласий (consent), показ рекламы несовершеннолетним.
- Сохранения (PlayerPrefs/JSON): отсутствие шифрования — данные только локальные;
  сообщения об exploit'ах прогресса принимаются, но не считаются уязвимостью.
- Сборка CI: компрометация секретов лицензии Unity.

## Заявления

- В игре **нет серверов**: персональные данные не собираются разработчиком.
  Сбор данных осуществляют рекламные сети согласно политике конфиденциальности.
- Секреты (ключи подписи, UNITY_LICENSE, ad unit ID продакшена) никогда не
  хранятся в репозитории — только в GitHub Secrets.
