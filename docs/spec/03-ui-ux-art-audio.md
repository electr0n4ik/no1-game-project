# «Рубилово» — Спецификация UI/UX, Арта и Аудио

- **Версия:** 0.1 · **Дата:** 2026-08-24 · **Статус:** черновик
- **Платформа:** Android 8.0+, RuStore · **Движок:** Unity 6.3 LTS, URP 2D
- **Базовый пак:** kenney.nl/assets/top-down-shooter (CC0, ~623 спрайта)
- **Ориентация:** портрет, управление одной рукой. Дизайн-канвас 1080×2340 (≈360×780 dp @3x)
- Связанные документы: `01-game-design.md`, `02-tech-architecture.md`

## 1. Карта экранов и навигационный флоу

Основной путь:

```text
Splash → Consent/Policy → Menu → Game → LevelUpOverlay → Game
      → ChestOverlay → Game → BossWarning → Game(бой с боссом)
      → ResultScreen → ReviveOffer → (Game | ResultScreen-финал) → Menu
```

Полная таблица переходов:

| Из | Триггер | В | Особенности |
|---|---|---|---|
| Splash | загрузка ≤3 с | Consent/Policy | чекбокс «Принимаю», без него — выход |
| Consent/Policy | «Принимаю» | Menu | одноразово, сохраняется в prefs |
| Menu | [Play] | Game | забег №1 запускает онбординг (разд. 4) |
| Game | LVL-up | LevelUpOverlay | `timeScale=0`, выбор 1 из 3 |
| LevelUpOverlay | выбор карты | Game | fade-out 200 мс, `timeScale=1` |
| Game | сундук с врага | ChestOverlay | пауза, анимация открытия |
| ChestOverlay | тап / [Забрать] | Game | авто через 4 с бездействия |
| Game | спавн босса | BossWarning | баннер 1.5 с, игра **не** останавливается |
| Game | ⏸ / системный Back | PauseOverlay | `timeScale=0`, музыка приглушается −40% |
| PauseOverlay | [Продолжить] | Game | отсчёт «3-2-1» перед возвратом |
| PauseOverlay | [В меню] | Menu | монеты за забег сохраняются |
| Game | HP = 0 | ResultScreen + ReviveOffer | ревайв — модал поверх результата |
| ReviveOffer | просмотр рекламы | Game | 1 попытка за забег, HP 50%, неуязвимость 2 с |
| ReviveOffer | отказ / таймаут 5 с | ResultScreen (финал) | таймер-кольцо на кнопке |
| ResultScreen | [Реванш] | Game | сразу новый забег |
| ResultScreen | [В меню] | Menu | interstitial со 2-го забега: шанс 100%, не чаще 1 раза в 3 мин |
| Любой экран | сворачивание приложения | автопауза | mute аудио; возврат в Game → PauseOverlay |
| Системный Back | из Menu дважды за 2 с | выход | диалог подтверждения не нужен |

Правила стека: оверлеи (LevelUp/Chest/BossWarning/Pause/Revive) живут поверх Game и не пушатся в историю Back; Back внутри них = безопасное закрытие.

## 2. Спецификация экранов

### 2.1 Menu

Композиция сверху вниз: логотип (25% высоты экрана) → [Play] → ряд [Shop][Quests] → шестерёнка Settings в правом верхнем углу под safe-area. Фон — поле #2B2D42 с 2–3 медленно бродящими силуэтами врагов (декор).

| Блок | Элементы | Размер | Состояния |
|---|---|---|---|
| Header | логотип «РУБИЛОВО» Baloo 2 Bold | h1 44sp | появление scale 0.9→1, 300 мс |
| Play | primary-кнопка | 320×72 dp | idle-пульс 1.00↔1.02 (2 с), press: звук+вибро |
| Shop | secondary-кнопка | 152×56 dp | блокировки нет |
| Quests | secondary-кнопка + красный бейдж наград | 152×56 dp | бейдж скрыт, если забирать нечего |
| Settings | иконка-кнопка | 48×48 dp | — |

### 2.2 HUD — см. раздел 3.

### 2.3 LevelUpOverlay

| Блок | Элементы | Поведение/состояния |
|---|---|---|
| Dim | fullscreen #000000 α60% | блокирует input геймплея, `timeScale=0` |
| Заголовок | «УРОВЕНЬ {lvl}!» h1 #FFD166 | слайд-даун 250 мс |
| Карта ×3 | иконка 96px + название h2 + описание body, рамка цвета редкости | вертикально, 320×96 dp; stagger 60 мс; рекомендованная — обводка #FFD166 3dp + стрелка 24dp |
| Перебор | text-button «Переброс ×1 (за рекламу)» | WOULD, скрыт в онбординге |

Выбор карты: подсветка 100 мс → confirm-scale 1→0.96→1 → закрытие 200 мс. Сворачивание приложения здесь = остаёмся в оверлее.

### 2.4 ResultScreen

| Блок | Элементы | Поведение |
|---|---|---|
| Титул | «ЗАБЕГ ОКОНЧЕН» / «ПОРАЖЕНИЕ» | h1, цвет #EDF2F4 / #EF476F |
| Статистика | время, убийства, уровень, монеты — сетка 2×2 | счётчик 0→N за 800 мс |
| Награды | строки «монета ×N», иконки 32px | появление stagger 80 мс |
| Кнопки | [Реванш] primary 280×64, [В меню] secondary | отступ между ними 12 dp |

### 2.5 ReviveOffer

Модал поверх ResultScreen: затемнение α70% → иконка клинка 128px → «Продолжить бой?» h2 → таймер-кольцо 5 с вокруг primary-кнопки [Смотреть рекламу] 300×64 → снизу caption-кнопка «Нет, спасибо». Таймаут/отказ → схлопывается в финальный результат. Показывается ≤1 раза за забег, начиная со 2-го забега (онбординг стерилен).

### 2.6 Settings

Список строк высотой 56 dp, разделитель 1 dp #8D99AE α20%, паддинг 16 dp. Состав — раздел 10.

### 2.7 Quests

Табы [Ежедневные | Все] (высота 40 dp). Строка квеста 72 dp: иконка 48 dp, название body, прогресс-бар 8 dp (#06D6A0), кнопка [Забрать] 48 dp высотой — активна только при 100%. Claim: конфетти WOULD, звук coin.

### 2.8 Shop

Валюта в правом верхнем углу (монета 24 dp + число 18sp). Секции: «За монеты» — метапрогрессия (HP, урон, магнит), грид 2 колонки, карточки 160×180 dp; «За рекламу» — x2 награда после забега, бесплатный сундук раз в 4 ч с таймером.

## 3. HUD

Canvas: Screen Space Overlay, reference 1080×2340, Match=1 по высоте. Safe-area вычисляется из `Screen.safeArea`, все якоря верхних элементов — от safe-top.

| Элемент | Позиция | Размер | Оформление |
|---|---|---|---|
| XP-бар | во всю ширину, y = safeTop+2 dp | высота 14 dp | fill #06D6A0, фон #1B1E33 α70%, вспышка при заполнении сегмента |
| Таймер | верх-центр, y = safeTop+22 dp | 34sp Baloo 2 Bold | белый + обводка 4 px rgba(0,0,0,.55) |
| Убийства | левый край 16 dp, y = safeTop+24 dp | иконка черепа 26 dp + число 22sp | обводка как у таймера |
| Монеты | под убийствами, y = safeTop+58 dp | иконка 22 dp + число 18sp | #FFD166 |
| Комбо | правее центра, поворот −6° | 28sp «x50!» | #FFD166, punch-scale на инкременте |
| Пауза ⏸ | правый край 12 dp, y = safeTop+16 dp | 48×48 dp | иконка, полупрозрачная плашка #1B1E33 α50% |

Читаемость на 5": минимальный текст HUD 14sp, контраст текст/фон ≥4.5:1, обводка обязательна (поле под текстом меняется). Тест-устройство: 5" 720p (360 dp ширина).

## 4. Онбординг (30 секунд)

Забег №1. Никаких слов, кроме «Тяни, чтобы двигаться». Реклама полностью исключена до конца забега №1 («стерильная зона» — критично для D1). Смерть невозможна: урон врагов ×0.5, регенерация HP постоянная.

| Время | Событие |
|---|---|
| 0–2 с | спавн героя; орбитальный клинок уже вращается — вау-момент с первой секунды (радиус 1.5 юнита, видимый трейл) |
| 0–5 с | подсказка жеста: полупрозрачная рука (α60%), цикл свайпа 1.5 с, текст «Тяни, чтобы двигаться» 18sp под рукой; скрывается после 1.5 с непрерывного движения или на 5-й секунде |
| 5–8 с | первая волна 3 врага; гарантированный килл демонстрирует juice: хитстоп + вспышка + цифра + отброс |
| 8–10 с | килл-подсветка клинка (вспышка _Flash) — игрок связывает оружие с убийствами |
| 15–18 с | гарантированный первый LVL-up (XP-кривая подогнана): автопауза → LevelUpOverlay, рекомендуемая карта подсвечена стрелкой 24 dp |
| 18–30 с | вторая волна, закрепление цикла; новых текстов нет |

## 6. Арт-дирекшн

**Принцип:** яркие насыщенные персонажи и враги на тёмном поле #2B2D42. Силуэт читается мгновенно (тест: переводим спрайт в ч/б — форма узнаваема). Мягкая blob-тень под каждым юнитом вместо реалтайм-теней.

**Палитра (12 цветов):**

| HEX | Роль | HEX | Роль |
|---|---|---|---|
| #2B2D42 | поле, фон | #06D6A0 | XP, успех, лечение |
| #1B1E33 | UI-панели, виньетка | #118AB2 | инфо, редкая редкость |
| #8D99AE | нейтраль, обычная редкость | #7209B7 | эпическая редкость |
| #EDF2F4 | основной текст | #F72585 | легендарная редкость, акцент босса |
| #FFFFFF | вспышки, крит-текст | #EF476F | опасность, потеря HP |
| #FF9F1C | огонь, средний приоритет VFX | #FFD166 | валюта, CTA, комбо |

**Масштаб:** PPU = 64 для всех игровых спрайтов. Герой 64×64 (1 юнит), враги 48–96 px (0.75–1.5 юнита), боссы 192 px (3 юнита). Размеры кратны 32.

**Kenney-паки:** `top-down-shooter` — база персонажей/оружия/тайлов; `particle-pack` — дым/искры/взрывы (перекрасить в палитру); `ui-pack` — заготовки панелей (перерисовать радиус под 16 dp); `game-icons` — служебные иконки. Расширение: только hue-shift в пределах палитры, единая толщина контура, никаких стоковых теней из паков.

**Иконки апгрейдов:** 96×96 px, шаг сетки 8 px, без текста внутри, силуэт + один акцент цвета редкости, атлас `UI_Icons_96`.

**Иконка приложения:** PNG 512×512 RGB (RuStore), два скрещенных клинка на щите, композиция читается на 96 px, безопасное поле 10%, без альфа-канала.

## 8. Локализация

Старт — RU, EN заложена архитектурно. Все строки только через TextMeshPro (UGUI), ключи вида `экран.элемент`, плейсхолдеры `{name}` (`string.Format`). Отсутствующий ключ → fallback EN → показ ключа (красным в дев-сборке).

```json
{
  "menu.play": "Играть",
  "menu.shop": "Магазин",
  "hud.hint.move": "Тяни, чтобы двигаться",
  "levelup.title": "Уровень {lvl}!",
  "result.kills": "Убито: {kills}",
  "revive.offer": "Продолжить бой?"
}
```

Файлы: `Resources/Loc/ru.json`, `en.json`; загрузка в словарь при старте, переключение языка в Settings без перезапуска. TMP-атлас: dynamic + fallback на кириллический источник. Числа и время (мм:сс) не локализуются.

## 9. Аудио

Mixer: Master → Music / SFX. Лимит голосов SFX — 8, приоритет по близости к игроку. Все боевые SFX — рандом питча ±15%.

| Имя | Характер | Длина | Детали |
|---|---|---|---|
| hit | глухой шлепок «мясо+металл» | 60–120 мс | 3 вариации, ≤6 голосов |
| kill | сочный поп с хрустом | 150–250 мс | главный «сок» жанра |
| levelup | восходящее арпеджио + звон | ~600 мс | без питч-рандома |
| chest | скрип крышки + короткое «тадам» | ~800 мс | — |
| boss-warning | низкий тревожный рог ×2 | ~1.2 с | duck музыки −40% на время |
| death | нисходящий питч + финальный удар | ~700 мс | lowpass на мастере 300 мс |
| button | мягкий клик | 40–80 мс | pitch ±5% |
| coin | высокий металлический «динь» | ~150 мс | pitch ±10%, ≤4 голосов |

**Музыка:** lo-fi hip-hop, 90–110 BPM, бесшовный луп 2–3 мин, без вокала, приглушённые верха. Источники легально: itch.io CC0 (фильтр по лицензии при скачивании), OpenGameArt CC0, генерация в Suno — только коммерческий тариф, фиксировать промпт/дату/ID трека в таблице ассетов.

**Ducking:** реклама открылась → Music −60% за 200 мс; закрылась → возврат за 400 мс. Вибрация: лёгкая на каждое 10-е комбо, средняя на levelup (если включена в Settings).

## 11. Accessibility

- **Дальтонизм:** опасность кодируется формой (шипы, размер, анимация) + цветом, никогда только цветом. Палитра врагов прогнана через симулятор протанопии/дейтанопии; #EF476F и #06D6A0 не пересекаются по смыслу на одном элементе.
- **Крупный текст:** опция масштаба 100%/125% для всех TMP, кроме цифр урона и таймера (фиксированы для баланса чтения).
- **Тапы:** ≥48 dp, учёт safe-area на всех экранах.
- **Эпилепсия:** никакие эффекты не мигают чаще 3 Гц.
- **Звук/вибро:** все сигналы дублируются визуально (boss-warning = баннер + рог).

## 12. Производительность UX — запреты

| Запрещено | Почему | Замена |
|---|---|---|
| Баннер/оверлей рекламы поверх геймплея | перекрывает пальцы, убивает D1 | реклама только между забегами и в модалах |
| Постпроцессинг (bloom, vignette, AA) | GPU-бюджет, мылит пиксель-арт | свечения — спрайтами в атласе, вспышка `_Flash` |
| Realtime shadows | CPU/GPU дорого | blob-тень спрайтом под юнитом |
| Fullscreen-прозрачные слои каждый кадр | overdraw | один dim-слой на оверлей, α≤60% |
| Instantiate/Destroy в бою | GC-spikes | пулы: цифры 30, монеты, снаряды, эмиттеры частиц |

Бюджеты: ≤100 draw calls, ≤100K tris. Sprite Atlas V2 (враги / UI / VFX отдельно), SRP Batcher включён, один материал на всех врагов — вариации только через PropertyBlock.
