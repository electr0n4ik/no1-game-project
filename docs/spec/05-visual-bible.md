# 05 · Visual Bible — как выглядит «Рубилово»

Версия 1.0 · дополняет спеку 03 (UI/UX) · источник правды по ВИЗУАЛУ.
Главный закон: **читаемость важнее красоты**. Силуэт-тест: любой объект
опознаётся за 0.3 сек на экране 5" в гуще боя.

---

## 1. Пропорции и камера
- PPU (пикселей на юнит) = **64**; спрайты рисуются в 64/128 px.
- Экран 5" (1080×2340) при ortho 5 видит ~9×19.5 юнитов; при ortho 9.5 (кап) — ~17×41.
- Камера: центр на игроке, зум по `scale^0.43` (спека 01 §3), тряска поверх.

## 2. Поле (арена)
| Элемент | Описание |
|---|---|
| Базовый пол | тайл 2×2u, тёмный сине-фиолетовый `#232538`, редкие пятна `#262840` (шум 8%) |
| Декор | пучки травы/камни/черепа из kenney **tiny-dungeon**, 1 объект на ~6u², alpha 60%, НЕ перекрывают геймплей |
| Граница | зубчатый бархан-вал высотой 0.6u, цвет `#3d4060`, внутри — светящаяся кромка `#ef476f` alpha 25% (понятен «тут нельзя») |
| Виньетка | радиальный градиент по краям экрана 12% чёрного — фокус в центр |

## 3. Игрок «Рубила»
| Параметр | Значение |
|---|---|
| Спрайт | kenney **top-down-shooter** `survivor1_hold` (человечек с оружием), тело 0.9u |
| Поворот | мгновенно по направлению движения; в покое — по последнему взмаху хлыста/направлению |
| Тень | эллипс 0.9×0.36u, чёрный alpha 35%, под ногами, НЕ вращается |
| Ходьба | боб-анимация: scaleY 1.00↔1.06 @8 Гц + лёгкое покачивание ±2° |
| Рост (агарио) | масштаб спрайта = scale; тень растёт пропорционально |
| Кольцо уровня | тонкое кольцо r=0.55u `#ffd166` вокруг ног; на levelup — вспышка кольца (расширение +0.3u, 0.25 с) |
| Урон игроку | красная вспышка виньетки 8% + тряска 0.15u (уже есть Punch) |

## 4. Орбитальные клинки
- Спрайт меча 0.7u (kenney `sword_generic`), остриё по касательной к орбите.
- След: 2 призрака позади на 12° и 24°, alpha 30%/12%.
- Попадание: белая вспышка меча 0.06 с + hitstop 40 мс (спека 03 §5).
- Цикл L4+ (uptime/простой): клинки «растворяются» — alpha → 0 за 0.15 с и обратно; на земле в простое рисуется пунктирная орбита alpha 20% — игрок видит, что способность «заряжается».

## 6. Орбы XP
- Сфера 0.14u `#ffd166` + внешнее свечение (круг ×1.8, alpha 25%).
- Пульс размера ±10% @2 Гц (фаза случайна — поле «дышит»).
- При магнит-притяжении — короткий хвост 2 призрака.
- Орб ×5 (слияние) — крупнее (0.2u) и цвет `#06d6a0`.

## 7. Эффекты (juice) — обязательный минимум
| Эффект | Параметры |
|---|---|
| Вспышка урона врагу | спрайт → белый 0.06 с (color flash) |
| Цифры урона | пул 30, всплывают 0.5 с на 0.6u, шрифт Baloo 18dp, криты (топор) 24dp жёлтые |
| Смерть врага | 8–14 осколков цвета тела, разлёт 1–2u, гравитация лёгкая, 0.4 с + «лопание» (scale 1→1.3→0) |
| Хитстоп | 40 мс на килл (заморозка таймскейла) |
| Тряска | 0.15u урон игроку · 0.05u каждый 25-й килл · 0.3u смерть босса |
| Комбо | «x50!» по центру-верху при 50/100/200/500 убийствах, scale-пружина |

## 8. HUD (сводка из спеки 03, канон)
- XP-бар: во всю ширину, высота 6dp, `#ffd166` поверх `#3d4060`, скруглённый.
- Верх-центр: таймер mm:ss (Baloo 22dp, тень 2dp).
- Верх-лево: `LVL n` в шестиугольнике-бейдже.
- Верх-право: счётчики ☠ kills · 🍖 meat (иконки 20dp).
- HP-полоса: под ногами игрока (мировая), 1.2u, зелёная→красная.
- Всё в safe-area, тап-таргеты ≥48dp.

## 9. Экраны
### Меню
- Фон: размытый скриншот арены (или тот же тайл-пол) + виньетка 30%.
- Лого «РУБИЛОВО» — рубленый шрифт, за ним 3 клинка по дуге (баннер уже есть: assets/banner.svg).
- Две плитки-кнопки 46% ширины: «КАМПАНИЯ 15:00» (иконка черепа-босса) и «ВЫЖИВАНИЕ ∞» (иконка песочных часов); под ними мелко рекорд времени.
- Низ: кнопки «Дерево 🍖», «Задания», «⚙».

### Выбор апгрейда (level-up)
- Пауза, затемнение 60%.
- 3 карты: ширина 30% экрана, высота 34%, радиус 16dp, рамка редкости (common `#b8bdd4` / rare `#118ab2` / epic `#9d4edd`), иконка оружия 96dp, название, «+X» эффект.
- Появление: stagger 60 мс, scale 0.8→1 пружиной.

### Смерть / Победа
- Затемнение 70%; заголовок «ПОРАЖЕНИЕ»/«ПОБЕДА» 40dp.
- Строки статистики (время, уровень, убийства, элиты, боссы).
- Блок мяса: иконка 🍖 + бегущий счётчик 0→N за 1.5 с (звон монет), кнопка «×2 🍖 (ролик)».
- Кнопки: «Возродиться (ролик)» → «Заново» → «В меню».

## 10. Палитра (16, финал)
```
фон        #232538  #262840  #2b2d42  #3d4060
акцент     #ffd166 (золото/XP)  #ef476f (урон/элита)
игрок      #fff5eb (единственный чисто-белый на поле!)
враги      #6a994e  #ffb703  #e76f51  #cdb4db  #90be6d  #f94144
боссы      #d90a99  #118ab2  #e5383b  #9d4edd
сервис     #06d6a0 (лечение/орб×5)  #b8bdd4 (текст вторичный)
```
Правила: игрок — единственный белый; враги — только из палитры врагов;
фон никогда не использует акценты; урон/опасность — всегда `#ef476f`.

## 11. Маппинг «круги превью → финальные спрайты»
| Сейчас (натив. превью) | Финал |
|---|---|
| красный круг игрока | спрайт survivor + тень + кольцо уровня |
| жёлтые точки-клинки | мечи со следом |
| голубые круги | зомби/пёс/огр/лучник/крысы/бомбер по таблице §5 |
| жёлтые орбы | сферы со свечением и пульсом |
| текст HUD | HUD из §8 |
