| Поле | Значение |
|---|---|
| Платформа | Android, RuStore |
| Движок | Unity 6.3 LTS, URP 2D |

## 1. Видение и УТП

**Одна фраза ценности:**

> «Ты — человечек с клинками на орбите: рубишь толпы, растёшь как в agar.io и через 5 минут уже кромсаешь экран целиком».

**Пилюля для карточки стора (до 80 символов):**

> «Руби тысячи врагов, расти до размеров карты — орбитальные клинки всё решают»

**Расшифровка УТП (3 опоры):**

1. **Мгновенно читаемый рост** (урок Hole.io/Paper.io, 414M установок): персонаж физически увеличивается от XP — это видно без слов, скриншот продаёт сам себя. Ни один survivor на RuStore этого не делает.
2. **Орбитальные клинки как сигнатура**: не «пули во все стороны», а вращающиеся мечи — уникальный визуал для иконки/видео, ноль текстового обучения.
3. **Честная реклама вместо paywall**: игрок видит rewarded только тогда, когда сам хочет x2 или revive. Никаких IAP — упрощает модерацию RuStore и юридический контур самозанятого.

**Анти-УТП (что мы сознательно НЕ делаем):**
- Не клонируем контент-конвейер Survivor.io (28 героев + экипировка = команда из десятков людей).
- Не выходим на Google Play / Steam в первый год: там bullet heaven — официальная категория Steam и рынок насыщен клонами; наша защищённая ниша — RuStore.

**Core loop (30–60 секунд цикл):**

```
Двигаешься → клинки рубят толпу → собираешь XP → персонаж РАСТЁТ (видно телом)
→ левел-ап: выбор 1 из 3 апгрейдов → толпа плотнее → клинки сильнее/больше
→ каждые 5 минут босс → смерть или победа → мета-валюта → апгрейд дерева → новый забег
```

Точка дифференциации в цикле — шаг «персонаж РАСТЁТ»: он конвертирует абстрактный XP в визуальный прогресс, который работает на ретеншен (D1) и на креатив для стора одновременно.

## 2. Целевая аудитория и позиционирование

### Портрет игрока RuStore

| Параметр | Значение |
|---|---|
| Ядро | Мужчины 16–35 лет, регионы РФ и СНГ |
| Устройства | Бюджетный/средний Android (Redmi, Realme, Samsung A) — отсюда URP и цель 60 FPS на Mali G52 |
| Опыт | Играли в Vampire Survivors / Survivor.io / Archero; ищут «во что убить время» без доната |
| Платёжеспособность | Низкая склонность к IAP, высокая терпимость к рекламе за награду — идеальный профиль под ad-only модель (ARPU $0.3–0.8 по рынку чистой рекламы) |
| Источники трафика | Органика RuStore + ASO; платный трафик не рассматриваем до M4 |

### Сценарии сессий

| Сценарий | Контекст | Что проектируем |
|---|---|---|
| «Микро-забег» | Очередь, транспорт, 3–7 минут | Забег 5–8 мин, выход в любой момент, interstitial только при рестарте после ≥120 сек геймплея |
| «Вечерний залип» | Дома, 20–40 минут | Цепочки забегов, мета-дерево даёт видимый прогресс между забегами |
| «Второй шанс» | Смерть на 6-й минуте | Revive за rewarded — самый сильный момент монетизации, уже реализован |

**Позиционирование:** «единственный survivor на RuStore, где ты растёшь телом, а не только цифрами». Против Survivor.io (донатный конвейер) и против premium-портов VS/Brotato (платить вперёд на мобильном не работает: Brotato mobile ~$20K/мес при 11.2M копий на PC).

### Вторичные сегменты

| Сегмент | Доля (оценка) | Что даёт | Риск отталкивания |
|---|---|---|---|
| Казуальные игроки io-жанра (Hole.io аудитория) | ~30% | Основной объём органики RuStore | Сложные билды → прячем глубину за туториалом ≤28 сек |
| Хардкорнее survivor-игроки | ~15% | D30-ядро, стримы/сарафан | Донатное давление и pay-to-win → у нас его нет by design |
| Женщины 25–40, «казуалка в одну руку» | ~20% | Удержание D7+ через мета-прогресс | Вертикальный геймплей с двумя пальцами — обязательно |

## 4. KPI-цели по этапам

Бенчмарк жанра: медиана D1 26–28%, D7 3.4–3.9%, сессия 5–22 мин. Хит: D1 35–45%, D7 10–15%.

| Метрика | Софт-запуск (M3) | Масштабирование (M4) | Действие при промахе |
|---|---|---|---|
| D1 retention | ≥35% | ≥40% | Перебаланс первых 3 минут, туториал ≤28 сек |
| D7 retention | ≥8% | ≥12% | Усилить daily-крючок: ежедневные задания |
| D30 retention | ≥3% | ≥5% | Мета-дерево глубже, новый персонаж |
| Средняя сессия | ≥8 мин | ≥10 мин | Сократить паузы, ускорить ранние волны |
| Playtime до 1-й рекламы | ≥120 сек | ≥150 сек | Никогда не нарушать — иначе D1 падает быстрее, чем растёт ARPDAU |
| Rewarded opt-in | ≥25% DAU | ≥35% DAU | Добавить x2 XP-предложение в конце забега |
| Interstitial показ / DAU | ≤3 | ≤4 | Лимит жёсткий: перегруз = отвал D1 |
| ARPDAU (реклама, РФ) | ≥₽2.5 (~$0.03) | ≥₽4 (~$0.05) | См. риски R2 (низкий eCPM) |
| Crash-free сессии | ≥99% | ≥99.3% | Блокировать релиз ниже порога |

**Экономическая рамка:** при чистой рекламной модели ориентир ARPU $0.3–0.8/установку достижим только на долгом горизонте удержания; при D7=10% и ARPDAU ₽4 проект выходит на окупаемость времени соло-разработчика при органике от ~15K установок/мес. Платный трафик — только если softlaunch-ARPDAU подтверждён.

### Инвентарь рекламных размещений (фиксируется на M2)

| Размещение | Тип | Триггер | Лимит |
|---|---|---|---|
| Revive после смерти | Rewarded | Игрок сам нажал | Без лимита (игрок решает) |
| x2 мета-валюта за забег | Rewarded | Экран результата | Без лимита |
| Ускоритель мета-апгрейда | Rewarded | Дерево, таймер 5–15 мин | Без лимита |
| x2 XP первые 60 сек забега | Rewarded | Старт забега | Без лимита |
| Interstitial при рестарте | Interstitial | После ≥120 сек геймплея | ≤3/DAU, никогда в первые 2 сессии |

Правило: rewarded всегда по инициативе игрока, interstitial — только «естественная» пауза (смерть → рестарт). Это защищает playtime до первой рекламы ≥120 сек и D1.

## 5. Нейминг и ASO

### A/B план названия

| Вариант | Сильные стороны | Слабые стороны |
|---|---|---|
| «Рубилово» (текущее рабочее) | Народное, запоминается, смешное, уникально для поиска | Звучит грубовато, слабее передаёт рост |
| «Крути-Руби» | Передаёт механику орбиты + действия, игровое звучание | Может прочитаться как детская игра |

**Протокол теста:** карточка RuStore с одинаковым креативом, два варианта заголовка, минимум 14 дней или ≥2000 показов карточки на вариант. Решающая метрика — CTR карточки → конверсия в установку. Если разница <15% — оставляем «Рубилово» (короче, брендируемое). Поддомены/соцсети проверяем на занятость до софт-запуска.

### Ключевые слова для описания

`выживи` `survivor` `рубилово` `арена` `толпы врагов` `офлайн игра` `без интернета` `клинки` `мечи` `рост персонажа` `волны монстров` `боссы` `казуалка` `аркада` `одна рука` `5 минут` `без доната`

Приоритет: «офлайн игра без интернета», «выживи», «survivor» — высокочастотники RuStore с низкой конкуренцией среди survivor-игр.

### Требования к иконке

- Читаемость 48×48 px: один силуэт — человечек + 2–3 ярких клинка на орбите, тёмный фон, кислотно-жёлтый/красный акцент.
- Без текста на иконке.
- 3 варианта для A/B: (1) клинки крупно, (2) человечек вырос до края кадра (агарио-рост), (3) толпа мелких врагов вокруг героя.
- Скриншоты: 1-й — момент рубки толпы, 2-й — сравнение «маленький → огромный», 3-й — экран апгрейдов. Подпись ≤4 слов на каждом.

### Структура страницы стора

| Элемент | Требование |
|---|---|
| Заголовок | ≤30 символов, победитель A/B из таблицы выше |
| Краткое описание (первая строка) | «Руби тысячи врагов и расти до размеров карты. Без доната.» |
| Полное описание | Первые 3 строки = УТП + «офлайн» + «5 минут»; ключевые слова из списка выше вплетены естественно, без спама |
| Видео | 15–30 сек: рост персонажа с маленького до экрана-заполняющего, без катсцен |
| Возрастной рейтинг | Заявляем 12+ (мультяшное насилие) — снижает барьер модерации |

## Приложение: чек-поинт принятия решения

После M3 (софт-запуск, 4 недели данных) выбираем один путь:

| Данные | Решение |
|---|---|
| D1 ≥35% и D7 ≥10% и ARPDAU ≥₽3 | Полный M4 + рассмотрение платного трафика |
| D1 ≥30%, но ARPDAU <₽3 | M4 без трафика; включить «убрать рекламу»; искать западную сборку (Google Play) как второй рынок |
| D1 <25% после 2 итераций онбординга | Заморозка проекта, публикация исходников как портфолио, новый концепт |

Документ достаточен для принятия решений по скоупу, срокам и go/no-go без дополнительных исследований.
