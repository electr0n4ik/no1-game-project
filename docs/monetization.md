# Монетизация (самозанятый, 2026)

## Вердикт исследований: всё легально ✅
| Источник | Самозанятому | Выплаты | Налог |
|---|---|---|---|
| Яндекс РСЯ (Mobile Ads) | **ДА** | от 3000 ₽/мес, р/с или СБП | **6% сам** до 25 числа |
| VK Ad Network | **ДА** (с 2024; физлица без НПД с 01.08.2025 не работают) | от 5000 ₽/мес, СБП | **6% сам** до 28 числа |
| Robokassa | **ДА** («Робочки СМЗ», чеки автоматом) | по договору | НПД |

- Лимит НПД: **2,4 млн ₽/год суммарно** по всем источникам — следить!
- Яндекс сам проверяет статус через ФНС по ИНН; нужно выдать права в
  «Мой налог» → Настройки → Партнёры.
- Чеки РСЯ и VK формируются автоматически в «Мой налог».

## Рекламные плейсменты в игре (проектирование дохода)
1. **Revive за рекламу** (rewarded) — главный источник, конверсия 15–30% смертей.
   Уже реализовано: DeathScreen → TryRevive.
2. **x2 награды в конце забега** (rewarded) — фаза 2 разработки.
3. **Interstitial при рестарте** — реализован с защитой:
   не чаще раза в 75 сек и не раньше 2-го забега (не убиваем ретеншн).
4. Баннер — НЕ используем (портит арену, eCPM низкий).
Ориентир eCPM РФ rewarded: ~100–400 ₽, interstitial ~50–150 ₽. Q4 выше на 30–50%.

## Порядок регистрации (до релиза)
1. Статус НПД активен: npd.nalog.ru / «Мой налог»
2. РСЯ: partner.yandex.ru → регистрация самозанятого → создать приложение →
   получить ad unit ID (`R-M-XXXXXX-Y`) → заменить `demo-*` в YandexAdsProvider.cs
3. «Мой налог» → Настройки → Партнёры → выдать права Яндексу (и VK)
4. VK Ad Network: ads.vk.ru → аккаунт «физлицо» → привязать VK ID →
   «Подключить самозанятость» → банк для СБП. Подключать вторым этапом,
   когда РСЯ уже капает — через медиацию Яндекса (адаптер myTarget) или напрямую
5. Robokassa: robokassa.com → тариф «Бизнес» для самозанятых → сервис
   «Робочки СМЗ» (чеки в «Мой налог» автоматом). Комиссия картами РФ ~3,4%

## Донат «поддержать автора» — ⚠️ серая зона
- RuStore: платная монетизация зарезервирована под ИП/юрлицо; кнопка внешней
  оплаты внутри приложения может трактоваться как обход системы → риск отклонения
- Безопасный вариант: ссылка/QR на **внешнюю страницу добровольного перевода**
  (страница Robokassa), без слов «купить/получить контент»
- Налоги: чистые подарки от физлиц НПД не облагаются (ст. 217 п. 18.1);
  если взамен даёшь бонус — это доход НПД 6%, нужен чек

## Приоритет запуска
MVP: только rewarded (revive) + interstitial (рестарт) через РСЯ. Всё остальное —
после первых выплат и метрик.
