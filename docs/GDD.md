# GDD: «Рубилово» (рабочее название)

## Концепция
Вид сверху. Человечек бегает по арене, вокруг него вращаются клинки и рубят
толпы врагов. Враги дропают XP-шарики → персонаж **растёт** как в agar.io:
больше размер = больше радиус клинков, но медленнее движение. Продержись
максимум минут. Жанр-гибрид: survivors-like × agar.io. На RuStore прямой
аналог не найден — пустая ниша.

## Почему залипает (из разбора хитов)
- Микронаграда каждые 20–30 сек: уровень → размер + новый клинок
- Смерть = мгновенный рестарт, «ещё один забег»
- Видимая мощь: рост персонажа на глазах
- Короткие сессии 3–7 мин (урок Survivor.io: длинные сессии убивают DAU)
- Билд решает больше, чем скилл (Vampire Survivors)

## Ядро цикла (реализовано в каркасе)
```
бегаешь → клинки рубят → XP-шарики летят к тебе → LVL UP:
  +размер, +клинок каждые 3 уровня → рубишь больше → ...
смерть → revive за рекламу ИЛИ рестарт (+interstitial раз в 2 забега)
```

## MVP (текущий каркас)
- [x] Движение drag-джойстик (+WASD в редакторе), замедление от размера
- [x] Орбитальные клинки: 2 базово, +1 за каждые 3 уровня, урон по кулдауну
- [x] Рост: scalePerLevel 1.06, кап ×4.5; XP-кривая `5 + 3·LVL`
- [x] Спавн волн кольцом за камерой: интервал 0.8→0.15 c, HP ×(1+t/45),
      кап 80 живых (слабые девайсы)
- [x] Пулы объектов (враги/шарики) — без GC-спайков
- [x] Revive за rewarded, interstitial с частотным капом
- [ ] Выбор 1 из 3 апгрейдов каждые 20 сек (следующий шаг!)
- [ ] Забег 5 мин с боссом на 3:00
- [ ] Мета-валюта за забеги (мясо) + прокачка между забегами

## Стартовый баланс
| Параметр | Значение |
|---|---|
| HP игрока | 100 |
| Урон клинка | 10 / hit / 0.25 c |
| HP зомби | 18 × difficulty |
| Скорость игрока | 4 u/c ÷ √scale |
| Радиус орбиты | 1.1 u (растёт со scale автоматически) |
| XP за врага | 1 + √HP·0.12 |

Смерть в первые сессии должна наступать на 2–4 попытке.

## Обязательный сок (полировка после MVP)
Хитстоп 30–50 мс на килл · отброс врага · белая вспышка спрайта ·
тряска камеры при уроне игрока (есть в CameraFollow.Punch) ·
цифры урона · частицы «лопания» · звук удара ±15% pitch · комбо «x50 МЯСО!»

## Название (A/B иконки+названия)
«Рубилово» vs «Крути-Руби» — оба читаемы в мелкой иконке, брендовых конфликтов
не найдено. Резерв: «Орбита Смерти», «Вырасти или умри», «Шар-Мясник».
