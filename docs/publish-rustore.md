# Чеклист публикации в RuStore

## Аккаунт
- Консоль: console.rustore.ru, вход по VK ID, тип аккаунта — **физлицо**
  (для бесплатной игры с рекламой этого достаточно; биллинг с 01.02.2026 только
  ИП/юрлицам, но он нам не нужен)
- Первичная регистрация может потребовать подтверждение причастности
  (документ в свободной форме) + авторизация по паспорту для физлиц

## Технические требования к сборке
- [ ] Формат: **.aab предпочтительно** (или .apk); для AAB заранее загрузить ключ подписи
- [ ] targetSdkVersion ≥ 28 (минимум), ставим **35**
- [ ] Обязательно arm64-v8a (64-bit), IL2CPP
- [ ] Вес артефактов версии ≤ 2 ГБ (у нас будет ~40–60 МБ)
- [ ] Подпись release-ключом, RSA ≥ 2048
- [ ] Приложение стабильно работает, нет крэшей на первом запуске

## Материалы карточки
- [ ] Название ≤ 50 символов («Рубилово» — свободно)
- [ ] Краткое описание ≤ 80 символов
- [ ] Полное описание ≤ 4000 симв., русский язык
- [ ] Иконка **512×512**, PNG/JPG ≤ 5 МБ (совпадает с иконкой на устройстве)
- [ ] Скриншоты **9:16**, JPG 1080×1920, минимум 3 (лучше 5) — реальный геймплей:
      арена, клинки, рост персонажа. НЕ арты без UI, НЕ функции которых нет
- [ ] Видео ≤ 2 мин, 16:9 или 9:16 (опционально, но конверсию поднимает)
- [ ] Возрастной рейтинг: скорее всего **12+** (мультяшное насилие)

## Юридическое (критично из-за рекламных SDK!)
- [ ] **Политика конфиденциальности обязательна** — рекламные SDK собирают данные.
      URL на страницу (можно GitHub Pages / Google Docs) + упоминание Яндекс/VK
      рекламных сетей и сбора advertising ID
- [ ] Экран первого запуска: согласие с политикой до инициализации рекламы
- [ ] Возрастное ограничение рекламы: `YandexAds.SetAgeRestricted(false)`
      — если аудитория может быть <13, поставить true (меньше eCPM, но безопасно)

## Запрещено (причины отклонения)
- Ссылки на другие магазины приложений
- Чужие товарные знаки, копирование иконок госприложений
- Азартные игры, порнография, призывы к насилию
- Кликбейт и функции «которых нет» на скриншотах
- Кнопки «оплатить на сайте» как обход платёжной системы (донат — только
  добровольная внешняя страница, см. docs/monetization.md)

## Процесс
- Модерация: официально <24 ч, реально **1–5 рабочих дней** (игры дольше утилит)
- После одобрения: RuStore Review SDK (запрос оценки) — опционально,
  работает только для опубликованного приложения
- Обновления: та же карточка → новая версия → повторная модерация
